# DSA Daily Practice

My daily learning log. I'm a college student learning Data Structures and Algorithms in Java.

Days 1 to 13 were pushed by hand, and each of those folders has its own README.

## From Day 14: LeetHub

From Day 14 onwards I'm using the LeetHub extension to push my solutions. Whenever a LeetCode submission is accepted, LeetHub commits it to this repo for me. The commit history is my daily record.

### Setup

1. Install the LeetHub extension in Chrome.
2. Sign in to GitHub from the extension and give it access.
3. Pick this repo when it asks where to push.
4. Open LeetCode and solve a problem.

### What gets pushed

- Each accepted problem is committed into its own folder.
- The folder has my Java solution and a README with the problem statement.
- The commit message is generated by the extension.
- Only accepted submissions are pushed.

### My routine now

1. Solve the problem in Java on LeetCode.
2. Once it is accepted, check that the new commit appears on GitHub.
3. If I improve a solution later, I submit it again and the new version is pushed.
